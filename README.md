# Trail Challenger

## Overview

Trail Challenger provide various types of challenges and of two categories that are as follows:

* Long Trail: This trek can continue for more than one day, and user has the option to pause and resume the trek but user will have to complete it otherwise it will get expired and he/she will have to purchase again.

* Day Hike: This trek lasts for 24 hour and less. this hike need to be completed once user has started it.

After successful completion of challenge user trail/hike duration will be displayed in leaderboard and after providing details like name, address etc some goodies will be delivered to user address and reward will be depending on various variables like rank etc.

## Installation:

1. open Gitlab.appventurez.com and open trail challenger project
2. copy http link of the project
3. open android studio and click on vcs
4. After that click on version control and paste you url and click on clone.
5. After compleeing the clone click on branches and choose sprin_2/UI
6. Checkout from that branch
